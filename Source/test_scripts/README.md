# Test Scripts

This directory contains scripts for starting the cloud services, running edge
experiments, checking TLS, and testing the transfer and attestation functions.

## Scripts

- start_cloud.sh: starts one cloud inference service in HTTP, AES-GCM, or ChaCha20-Poly1305 mode.
- run_all_cloud_modes.sh: starts the cloud services for all three transport modes.
- run_edge_comparison.sh: runs an edge inference experiment against one cloud target.
- run_all_modes.sh: runs the complete normal VM, TDX VM, and local inference comparison.
- check_tls_version.sh: checks the TLS versions and cipher suite accepted by a cloud endpoint.
- test_attestation.py: performs a real TDX attestation test without mocks.
- test_transfer.py: tests embedding transfer, TLS verification, session reuse, and response handling.
- validate_split.py: compares text generated by split inference with nanoVLM output.

## Preparation

Initialize the Python environment:

```bash
source Source/init.sh
```

Build the TDX attestation helper on both the edge and cloud VMs:

```bash
cd Source/tdx_attest
./build.sh
cd ../..
```

## Cloud Services

Start all transport modes on a normal VM:

```bash
ATTESTATION=disabled bash Source/test_scripts/run_all_cloud_modes.sh
```

Start all transport modes on a TDX VM:

```bash
ATTESTATION=enabled bash Source/test_scripts/run_all_cloud_modes.sh
```

Start one transport mode:

```bash
ATTESTATION=disabled bash Source/test_scripts/start_cloud.sh http
ATTESTATION=enabled bash Source/test_scripts/start_cloud.sh https-aes-gcm
ATTESTATION=enabled bash Source/test_scripts/start_cloud.sh https-chacha20
```

## Edge Experiment

The edge experiment script accepts:

```text
run_edge_comparison.sh <transport> <cloud-target> <inference-mode>
```

Example using the normal VM:

```bash
ATTESTATION=disabled bash Source/test_scripts/run_edge_comparison.sh \
  https-aes-gcm 10.128.0.7 split
```

Example using the TDX VM:

```bash
ATTESTATION=enabled bash Source/test_scripts/run_edge_comparison.sh \
  https-aes-gcm 10.128.0.6 split
```

Run the complete comparison using the target addresses configured in
run_all_modes.sh:

```bash
bash Source/test_scripts/run_all_modes.sh
```

## Tests

Run the real attestation test on a TDX VM:

```bash
sudo -E Source/.venv/bin/python Source/test_scripts/test_attestation.py
```

Run the transfer tests:

```bash
Source/.venv/bin/python -m unittest Source/test_scripts/test_transfer.py
```

Check the AES-GCM TLS endpoint:

```bash
bash Source/test_scripts/check_tls_version.sh 10.128.0.7 8443
```

## Output

The experiment scripts write logs, PID files, metrics, and throughput results
to Source/record/.
